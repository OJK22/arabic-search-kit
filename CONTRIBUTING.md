# Contributing

Thanks for considering a contribution.

1. Open an issue for behavior changes or larger features.
2. Include Arabic input examples that demonstrate the problem.
3. Add or update tests for every behavior change.
4. Run `npm test` and `npm run build`.
5. Keep default normalization conservative; explain any new false-positive trade-offs.

Please do not include private library records, personal information, or production data in issues or tests.
