# Changelog

Notable user-facing changes are documented here.

## 0.2.0

- Add query-token coverage scoring with `scoreArabicSearchMatch`.
- Add stable result ranking with `rankArabicSearchResults`.
- Deduplicate repeated query tokens in the all-terms matcher.
- Expand automated coverage for scoring, ranking, and duplicate terms.
- Improve package metadata and documentation.

## 0.1.0

- Add Arabic text normalization.
- Add tokenization and all-query-terms matching.
- Include TypeScript declarations and automated tests.
